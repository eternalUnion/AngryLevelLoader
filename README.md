### ℹ️ Note for modders
This repository has a wiki on how this project can be referenced in other mods.

# Angry Level Loader
Load levels made on Rude Level Editor. Levels are available online and can be downloaded in game. Records can be posted on the leaderboard, separated from the official steam leaderboard.

# Make Your Own Levels!
With [Vanity Reprised](https://github.com/eternalUnion/VanityReprised), you can use your copy of Ultrakill to generate a Unity project for building your own custom levels. There are not many resources on making levels using this editor, but several communities can provide help (mainly `ULTRAKILL Mapping` discord community server, which is dedicated to this editor). While the level editor is public, publishing your levels to the online catalog requires you to make an application. If you want to publish your levels on the online catalog, see pinned message in the #ultrakill-modding channel of the New Blood discord server.

# Note about old levels
Older levels (pre-revamp update) are separated from post-revamp levels due to compatibility issues. Older levels can still be downloaded if ULTRAKILL is downpatched to the violence update and correct versions of Angry and Plugin Configurator are used.

# Usage
1. Open settings
2. Click `PLUGIN CONFIG`
3. Select `Angry Level Loader`
4. Click `Online Levels` to download levels
5. Open the bundle and click the level thumbnail to launch the level

Note: you can also access the main panel from the act select menu
